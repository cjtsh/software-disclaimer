# Changelog

Notable changes to this project are recorded here. Versions follow [Semantic Versioning](https://semver.org/).

## [1.1.0] - 2026-10-21

### Changed

- Removed personal-name references from current public-facing notices and clarified that LLC attribution should be used only for rights the LLC owns or has received by assignment.
- Narrowed the indemnity to specified third-party claims caused by user conduct and added notice, defense-control, and settlement procedures.
- Clarified that posted notices do not automatically form contracts, and corrected overbroad statements about UCC coverage, liability waivers, and LLC protection.
- Updated first-run and README templates to emphasize clear presentation and affirmative assent where contractual terms are intended.

## [1.0.0] - 2026-10-21

Initial versioned release of the standard software disclaimer framework.

### Added

- User indemnification language covering specified third-party claims, subject to applicable law and acceptance of the terms.
- Warnings for autonomous agents, large language models, generated code, automated commands, and API calls.
- Prohibition on hazardous and mission-critical uses.
- Financial, legal, tax, and regulatory advice disclaimer.
- Florida governing law and Palm Beach County venue terms, with expanded severability language.
- Protected-party definition covering Bitseeker LLC and its members, managers, officers, employees, agents, and contributors.
- Matching short-form README and first-run notices.

### Changed

- Updated the root MIT license copyright attribution to Bitseeker LLC.
- Updated the README to summarize the protections and identify the current version.
